# Asset Studio defaults

These files are user-supplied raster sources copied byte-for-byte into new
projects. They are never regenerated or recolored on disk. Their checksums,
dimensions and current provenance status are recorded in `manifest.json`.

- `beam-thread.png`: default Beam thickness texture.
- `button-primary.png`: first original Button image.
- `button-secondary.png`: second original Button image.

Public redistribution is not currently authorized: the author, rights holder,
license and written evidence still need confirmation. The public-release gate
must remain red while any manifest entry has `redistribution.status` set to
`pending` or a license set to `UNRESOLVED`.
